# ОРБИТАЛЬНАЯ ОБОРОНА (ORBITAL DEFENSE v2.3)

Консольная аркадная игра в жанре космического шутера (bullet-hell) на Python с использованием только стандартной библиотеки.

## Описание проекта
Игрок управляет истребителем, переживает волны противников и метеоритов, собирает капсулы снабжения и сражается с боссами.

### Основные механики
- 3 вида оружия: пулемёт (1), ионный лазер (2), самонаводящиеся ракеты (3).
- Нагрев орудий и энергощит (X).
- Капсулы снабжения и сохранение рекорда в ~/.orbital_defense_score.json.

## Запуск и управление
- Запуск: python3 ./orbital_defense.py (минимальный размер терминала: 66x22).
- Стрелки / WASD — движение и выбор в меню.
- ПРОБЕЛ — стрельба (удерживать).
- 1 / 2 / 3 — смена оружия.
- X — щит, P — пауза, Q / ESC — меню / выход.
